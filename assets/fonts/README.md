# Tipografías Monoespaciadas (HUD Retro)

Este directorio está reservado para fuentes monoespaciadas personalizadas (`.ttf` / `.otf`) para la interfaz estilo terminal CRT.
Por defecto, el HUD en `egui` utiliza su fuente monoespaciada integrada (`FontFamily::Monospace`) con paleta de fósforo verde, ámbar o cian para garantizar portabilidad inmediata en Windows 11 y WebAssembly (`trunk serve --release`) sin requerir descargas externas.
